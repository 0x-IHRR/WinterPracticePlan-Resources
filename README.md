# WinterPracticePlan-Resources

A curated collection of learning materials, meeting summaries, and professional guidance for individuals transitioning into the Web3 ecosystem. This repository serves as a knowledge base for the Winter Practice Plan, covering everything from technical fundamentals to career advice.

## 📚 Contents

The repository is divided into two main categories:

### 📝 Meeting Summaries (`1.14_colearning_会议总结.md`)
Comprehensive notes from co-learning sessions covering critical Web3 topics:
- **Security & Risk Management**: Best practices for wallet security, signature risks, and tool recommendations (e.g., SCAM SNIFFER).
- **Career Guidance**: Tailored advice for various roles including:
    - **Technical/DevRel**: GitHub portfolio building and documentation standards.
    - **Product Management**: Balancing technical knowledge with community insights.
    - **Operations/BD**: Quantifying achievements and leveraging social platforms (Twitter/X).
- **Technical Deep Dives**: Explanations of stablecoin mechanisms (Centralized vs. Decentralized), 51% attacks, IPFS, and the competitive landscape of Public Chains (Layer 1 vs. Layer 2).
- **Data Analysis Tools**: Recommendations for tools like Dune, RootData, and Surf AI.

### 🔗 Resource Directory (`resources_link.md`)
A directory of external links and documentation including:
- **Foundational Learning**: Web3 operating principles and "Web2 to Web3" translation guides.
- **Course Materials**: Aggregated links to session recordings and presentations.
- **Technical Analysis**: Detailed breakdowns of Uniswap's working principles.
- **Industry Glossaries**: Guides on Web3 slang, abbreviations, and financial concepts.
- **Job Hunting**: Curated lists of Web3 job boards.
- **Operational SOPs**: Public SOPs for LXDAO and Hackathon preparation.

## 🚀 Getting Started

Since this is a resource-based repository, there is no installation required. You can use it as follows:

1. **For Beginners**: Start with the `resources_link.md` file and explore the "Web3 Operating Principles" and "Web2 to Web3" guides.
2. **For Career Seekers**: Read the "求职与作品集建议" (Job Search and Portfolio Suggestions) section in `1.14_colearning_会议总结.md`.
3. **For Developers**: Check the DevRel and Technical sections for insights on how to contribute to the ecosystem.

- **Analytics**: [Dune](https://dune.com), [RootData](https://rootdata.com).
